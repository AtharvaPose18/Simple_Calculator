# Java Calculator

## Description
A simple calculator program developed using Java. It uses a switch-case statement to perform basic arithmetic operations.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Checks for division by zero
- Accepts input from the user
